# MYATRI 角色设定填写表

不必一次填完；先写你最在意的部分即可。当前程序已能用默认模板启动，这份设定用于把示例角色变成你想要的正式角色。

```text
角色来源：原创，或作品名称/角色/版本；希望还原到什么程度？
名字与身份：角色如何理解自己？活动在什么世界或背景？
与我的初始关系：刚认识/已熟悉/其他；如何称呼我？
说话方式：语气、长短、主动程度；给1～2句你喜欢的表达。
始终保留的设定：哪些身份、原则和特征不希望随经历自动改变？
允许成长的部分：表达方式、偏好、处理分歧的习惯或关系认识等。
不喜欢的表现：例如口癖、过度附和、频繁解释系统原理等。
对话样例：给2～3个情境，写出你希望与不希望的回应。
```

工程提示词、结构化输出、来源/版本、压缩与激活工具由主Agent维护。背景故事作为角色设定保存，不能伪装成已真实发生的用户互动；当前临时心情不宜直接写成永久人格。

当前实际入口：config/persona_template.md的## P01、## P02、## P03等稳定条目。现在的P03“分歧时通常先迁就”是测试示例，不是已确认的人设；可以重写整个初始卡并新增稳定条目ID。

2026-10-21已导入小温暖1.0原卡及可加载版本，见[角色配置](../config/personas/xiaowennuan/README.md)。运行规则已改为遵循当前人格中的名字与身份，CLI显示名可以单独设置。不可自动修改的条目当前仅有prompt约束，没有程序硬锁。已有角色库初始化不会被模板文件静默覆盖；已有条目通过persona edit生成新版本，新角色卡用于新库init --persona-file。不要直接修改已发布records/commits。

预算、Embedding后端、夜间/空闲时段可以后续调整，不阻塞角色设定试用。官方API key已保存在本机Windows凭据管理器，无需重新填写或写入此表。
