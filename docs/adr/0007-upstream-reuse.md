# ADR 0007：按行为契约局部改编上游代码

2026-10-20，MYATRI 0.1.2。用户明确要求重读 A-MEM 与 Letta 源码，并复用现有代码中功能完全一致的部分。

采用两处可由现有接口承接的小型代码改编：A-MEM 的关联邻居去重与数量限制内核；Letta Code 的同目录排他临时文件、同步落盘、原子替换与失败清理内核。前者接 `MemoryGraph.get_subgraph` 与生产回忆，后者接档案及索引发布。原始来源、固定提交、文件/函数/行范围、修改与许可见 `LICENSES/upstream/manifest.json`。

这不是整套运行时接入。A-MEM 可变旧笔记与位置索引、默认集合 reset，以及 Letta 宽松工具历史修补、摘要/分块的文本变化，不与本项目固定来源、版本、完整协议等价，未移植。不为增加复用数量接入第二套权威记忆或新增模型调用。

保留已定义的行为：typed edges 与快照过滤、原回忆路径与上限、manifest-last、单写者、目录 fsync、原文无变换、异常向上传播。改编明确修正临时文件碰撞误删与清理错误遮蔽主异常，POSIX 新文件沿用上游 0600；Windows 不宣称获得 POSIX 权限/ACL 保证。兼容、崩溃恢复与故障注入测试验证这些边界。
