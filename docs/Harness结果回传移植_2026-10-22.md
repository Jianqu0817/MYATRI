# Harness 同轮结果回传移植

本次将 AstrBot `19a320d2d6f15b85c1f16fbfeedbe44410963e97` 中可移植的电脑执行及回复修复接入 MYATRI 完整 CLI。原核心库仍独立保留，不复制微信群档案，不替换 AstrBot 冻结依赖。

## 当前行为

- 菅蘧可以使用自然语言或 `/pc 任务` 提出电脑请求。主对话先生成执行指令，宿主绑定原始用户目标、稳定身份和会话，再提交 Harness。
- 执行期间原轮持久挂起；工具实际结果返回同一 `tool_call_id` 后，小温暖在原轮生成最终回复。终端报告轮询即使主动闲聊关闭也工作，不再只接收任务号。
- 单次 `--message` 模式也等待结果后输出；交互终端继续接受状态、暂停等后续指令。
- 重启时保留待回传的工具协议，避免启动重载上下文清掉任务。续接器使用 CLI 原档案目录定位检查点，不假设档案位于群 scope 子目录。
- 查询时刻、结果摘要和校验状态可回到主对话。缺少完成调用时保留报告并只补一次收尾；引用错误或空校验先提示真实回执 ID，连续三次校验失败后明确受阻，不伪装完成，也不要求用户补充并不存在的条件。
- 保留换行及显式消息分隔，保护多行引用和代码，避免两段回复粘连。

## 核心边界

继续使用原 `var/xiaowennuan` 或 `var/myatri-main`、内部 `atri/local` 身份、原 provider 账本、PrivateRecall、0.3.0 人类证据门控及 8776–8778 本机界面。角色卡和维护频率未修改；旧任务合同、结果不明不重放、取消优先和原限额继续有效。

未移入 AstrBot 专属的微信接入、唤醒关注、群聊与同库终端互斥入口、群库选择器、微信启动脚本或任何真实账号配置。MYATRI 已有自己的完整私聊入口，无需复制 AstrBot 的 `Start-Local-Chat.cmd`。

旧来源清单保留不变，本次增量来源及适配文件哈希记录在 `harness_feedback_port_source.json`。哈希取 Git blob，避免 Windows 换行导致不一致。
