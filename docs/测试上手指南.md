## 1. 先建立独立离线测试库

打开PowerShell。下面整段在同一个窗口运行，保存`$trialRoot`供后续步骤使用；每次重新开始测试可以生成新目录，不覆盖已有角色库。

```powershell
Set-Location D:\DS_workspace\MYATRI
$trialRoot = 'var/manual-test-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
.\.venv\Scripts\myatri.exe --root $trialRoot init
.\.venv\Scripts\myatri.exe --root $trialRoot chat --mode offline --message '测试约定：明天下午三点一起去图书馆，我比较期待。' --message-id trial_plan
.\.venv\Scripts\myatri.exe --root $trialRoot chat --mode offline --message '后来图书馆安排取消了，我有些失落。' --message-id trial_cancel
```

预期：初始化显示persona@1；两次回复明确写离线演示。每次单轮chat退出前会处理当前就绪后台任务，不必另开worker。离线A1是字面整理，日期/情感推断不等于真实语义理解；复杂认知通常defer，临时状态为空、人格不变都正常。

## 2. 看数据和来源，不只看聊天回复

```powershell
.\.venv\Scripts\myatri.exe --root $trialRoot recall '图书馆取消安排' --explain
.\.venv\Scripts\myatri.exe --root $trialRoot memory inspect trial_plan
.\.venv\Scripts\myatri.exe --root $trialRoot state list
.\.venv\Scripts\myatri.exe --root $trialRoot persona show
.\.venv\Scripts\myatri.exe --root $trialRoot jobs list
.\.venv\Scripts\myatri.exe --root $trialRoot doctor
```

检查：原话能精确读取；Recall有ref/source_refs/reasons及检索局限；任务失败/延期要看error，不把job存在当完成；doctor的ok应为true。doctor主要查档案和部分巩固关系，不能证明语义正确、所有队列成功或本轮新发现的索引缺陷已修。

## 3. 测试压缩与重启恢复

```powershell
.\.venv\Scripts\myatri.exe --root $trialRoot compact --preserve trial_plan
.\.venv\Scripts\myatri.exe --root $trialRoot context
.\.venv\Scripts\myatri.exe --root $trialRoot memory inspect trial_plan
.\.venv\Scripts\myatri.exe --root $trialRoot recall '图书馆约定取消' --explain
```

这些CLI命令每次都启动新进程，能检查跨进程读取；不是同一个Python对象里假装重启。压缩后trial_plan完整原文仍存在。当前压缩是有来源摘录，不是神经语义摘要。

关闭PowerShell后继续时，先Set-Location，再把`$trialRoot`设为你刚才实际生成的目录，不要重新生成时间戳。运行目录保留在var下，不要手改records/commits。

需要备份/恢复时：

```powershell
$backupPath = 'var/manual-backup-' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '.zip'
$restoreRoot = 'var/manual-restored-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
.\.venv\Scripts\myatri.exe --root $trialRoot backup --output $backupPath
.\.venv\Scripts\myatri.exe restore --input $backupPath --target $restoreRoot
.\.venv\Scripts\myatri.exe --root $restoreRoot doctor
.\.venv\Scripts\myatri.exe --root $restoreRoot memory inspect trial_plan
```

备份zip位于测试库之外；恢复目标必须尚不存在。备份含聊天原文，应按用户数据保管。

## 5. 最后体验真实对话

本机config/live.local.toml存在，先前key已存Windows凭据，不需要再把key写入文件。只启动一个实例，并使用与离线库不同的新目录。

```powershell
$liveRoot = 'var/manual-live-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
.\.venv\Scripts\myatri.exe --config config/live.local.toml --root $liveRoot chat --mode live
```

该命令会调用付费DeepSeek，并启动后台认知，一轮聊天可能对应多次请求；当前配置的日额度不能当成跨实例共享硬费用上限。建议先用少量虚构材料试3～5轮，避免一开始连续灌入长历史。程序不运行时不进行后台思考。

可以依次输入：

1. “测试场景：我们约好周末看电影。安排变化时，我希望你先和我确认。”
2. “测试场景续接：这次临时取消，我有些失落，但并不是责怪你。”
3. “我刚才说，希望安排变化时你怎么做？请区分我的原话和你的理解。”
4. 输入`/compact`，再问“刚才的约定还记得吗？”
5. 输入`/quit`退出。

评价它是否记得约定、区分事实/转述/推测、避免捏造原话、保持暂定性。少量测试不应强制让人格发生变化；对话问答正确也不等于已验证长期检索，因为近期原文仍可能在上下文里。

退出后检查：

```powershell
.\.venv\Scripts\myatri.exe --root $liveRoot jobs list
.\.venv\Scripts\myatri.exe --root $liveRoot state list
.\.venv\Scripts\myatri.exe --root $liveRoot persona show
.\.venv\Scripts\myatri.exe --root $liveRoot cost inspect
.\.venv\Scripts\myatri.exe --root $liveRoot doctor
```

这些检查命令默认offline，不会继续执行付费队列；cost是本地usage与配置估价，不是账户实际账单。交互退出会停止后台，pending或租约未释放的running任务可保留，不等于已成功；failed/deferred看error。
