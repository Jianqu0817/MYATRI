# 0006：持续运行、有限注意与有来源的行为归因

2026-10-20。用户授权修复代码审查问题，并要求以角色自然、持久化效果为设计方向。本轮主代理负责公共契约、app/runtime/gateway、行为归因、集成和公共文档；三个子代理分别负责记忆/检索、上下文压缩、认知材料规划，文件归属互不覆盖。

角色自然性落实为：原文可回查，解释允许变化，有限注意不等于遗忘，激活不等于行动，沉默不等于失败，犹豫/暂缓/放弃均合法，稳定人格只由有来源的局部提案改变。程序保障来源、版本、隔离和有限资源，不用时间、次数或模型自评机械制造人格成长。长期拟人效果需独立场景评价，不能由结构测试直接证明。

修复范围：重复自动压缩与增量原文整理；历史快照与索引单调发布、历史证据版本；有界认知选材；本地计算让出前台；时间与调度；共享预算预留；公共临时状态不变量；日常表达/反馈的后台归因。Entity/Skill/Procedure、外发渠道与通用工具执行不属于本轮修复。

语义压缩重用已逐字核验的旧要点时，继续指向原始消息/字符区间，不把旧摘要当作新证据。未处理片段保留游标与原文，不能将未看完的材料标为已覆盖。模型失败必须明确保留原状态或降级，不发布半份语义成功。

行为归因由后台模型提出：确切助手原文是否表达某个当时存在的意图，后续用户事件是否反馈了已记录表达。程序核验逐字引文、时间先后、候选范围、当前版本和幂等性；只支持本地会话 expressed，无外部执行证据不标 attempted；没有反馈时 outcome_unknown 保持 true。模型可 defer，不因激活或对话次数生成行为。归因记录是有来源的解释，不成为独立外部事件。

公共状态 create 不允许直接 consolidated；退休状态若重新考虑，应建立新 ID 并引用旧状态，保留放弃历史。新写入的 review_at/last_relevant_at 必须包含时区并规范为 UTC；已有档案中的纯日期/无时区日期时间由调度按配置本地时区解释。非法旧时间由调度隔离并报告，不能使整个后台退出。时间只决定何时复审。

共享日额度使用 SQLite 事务做跨实例预留。网络结果不确定时保守记占用，避免把超时视作免费；它仍不是供应商账单证明。材料超限和当天额度耗尽采用不同恢复策略。测试默认全部离线；本轮不扩大历史付费测试范围。

验收包括连续多次压缩/重启、来源仍可读、更新状态后索引继续推进、历史快照不见未来图、旧重建不倒退、并发前台心跳、规模增长下模型请求有界、到期复审读取新证据、多个实例共享预留，以及聊天表达和迟到反馈真实接入后的恢复/重复处理。已确认修复项纳入默认正常 pytest，不保留预期失败冒充成功。
