# 0.2.0 检索与群聊质量更新

2026-10-21补丁：[最早记忆读取修复](最早记忆读取修复_2026-10-21.md)。原始记忆完整，已重建两份私聊与当前群索引；新增早期原文定位和嵌套迁移来源读取，避免将索引维护说明当成记忆丢失。

更新核心，兼容相邻MYATRI-AstrBot 0.2.0。未修改角色卡，未自动重启现有服务；GitHub发布等待用户确认。

- 检索允许同一档案链的已验证基础索引加当前增量；旧版本与未来快照排除，图和主题仍核对快照。候选来源可在预算和向量Top-K之前筛选；用有界堆代替构造全量返回结果。
- 结论可与原话、解释及明确引用共同分配预算。原有词面、向量、图路径、反证及来源版本约束继续有效。
- 上下文的回忆字符预算可配置。Conversation支持宿主注册只读工具及针对性回复审查钩子，不改原私聊默认行为。
- 群聊A1可由宿主启用语义支持审查，核对否定、转述与结论力度；审查拒绝不发布Event。提取草稿持久保存，审查失败重试不重新提取。旧群聊记录也可经宿主开关启用；普通私聊兼容旧路径。
- 已有BGE ONNX推理限制CPU线程，并支持本机模型存在时的auto选择；模型缺失时保持词面基线。模型版本与向量空间继续验证，不混合不同空间。

多人话题、更正投影、30天冷档、原文只读工具、针对性回复检查、合成评测及人工验收，见相邻桥接项目 `docs/群聊质量升级与人工验收_0.2.0.md`。本轮没有把模型审查、向量相似、重复回忆或时间经过当成新外部证据，也不据此自动提升人格。
