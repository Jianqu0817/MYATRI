# 0.1.9 群聊记忆兼容更新

2026-10-21：为独立的 MYATRI-AstrBot 群聊桥接升级核心兼容能力；本次未修改角色卡或同步GitHub。

`Conversation.respond` 接受可选metadata，将渠道提供的真实成员信息连同原始消息持久保存。已有消息重试沿用原metadata，避免幂等冲突。

A1提炼群聊信封时，仅从顶层当前text选取材料，不把近期其他人的话归给当前发言者。校验逐字引文的实际位置、真实发言ID、自述对象与转述对象，并保留未确认标记；拒绝跨成员复用旧Event。个人微信身份来自渠道ID，不来自昵称或文本自称。普通私聊提炼继续兼容。

`read_record`工具增加offset/limit分页。长记录默认返回第一页及总长度、下一页位置与来源信息，避免因超过6000字节工具上限而完全无法阅读。短记录保持原返回形式。

旁听20/200/100/10、群聊15轮完整对话与成员注册表位于独立桥接项目，详见相邻 `MYATRI-AstrBot/docs/群聊上下文与旁听记忆_0.1.3.md`。原私聊记忆和群迁入记录保持原版本，不重写旧事实，也不将新摘要视作独立外部证据。
